پنل مدیریت GitHub

این پنل برای GitHub Pages به‌صورت مستقیم به GitHub API وصل می‌شود. توکن فقط در همین مرورگر و تا زمان بسته‌شدن تب نگه داشته می‌شود. برای توکن یک Fine-grained PAT فقط با دسترسی Contents: Read and write روی همین Repository بسازید. توکن را با کسی به اشتراک نگذارید.
